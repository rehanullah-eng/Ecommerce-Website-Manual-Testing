# Ecommerce Website - Manual Testing

This project contains complete manual testing documentation for an Ecommerce Website.

## What is included in this project?
- Test Scenarios
- Test Cases with Steps & Expected Results
- Bug Reports with Severity & Steps to Reproduce

## Modules Covered:
- Login / Signup
- Search
- Cart
- Checkout
- Payment

## Tools Used:
- Manual Testing
- Microsoft Excel
- Git & GitHub
